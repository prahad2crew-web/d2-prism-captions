# D2 PRISM — project rules (approved caption identity)

The creator has approved a **two-font caption preset**. This replaces the older single-font Barlow Condensed version for NEW reels. **Do not silently revert** to Barlow, Tamil-script captions, gold, cyan, electric lime, or the earlier giant-word design.

## Current approved look
- Large important keyword: **ANTON**, uppercase, electric-orange face / subtle gradient #FF7A00 → #FF5A00 → #E64A00, deep-navy #101B38 3D extrusion, restrained shadows.
- Smaller supporting words: **Inter SemiBold**, white, uppercase, normally ABOVE the orange word. Note: the original inspiration was an Anton + Poppins pairing, but the video the creator actually approved used **Anton + Inter SemiBold**. Prefer visual fidelity to that approved example over its inspiration image.
- Keep text spacious (2–4 spoken-meaning words/group, max 5 where needed), one important orange keyword/group, strong typographic hierarchy, not a cramped subtitle block.
- Use two caption tiers when natural: quiet Normal and occasional more impactful Hero. The approved dual-font typography must stay consistent.
- Keep face, chin, hands, key visuals, and Instagram UI clear. A prior caption "IT USES A / DEFAULT WEIGHT" had to be moved DOWN to clear the chin. Assess each new shot individually, adjust placement at cuts rather than constantly moving.
- For Tamil/Tanglish spoken audio, create **conversational ENGLISH visible captions**, phrase-synchronized. Do not fabricate timing for English words that are translations of differently ordered Tamil words. Flag uncertain words/numbers for review.
- The original video/audio and intentional transitions must be preserved. Don't put captions on intentional full-black frames unless user approves.
- Never obscure charts/calculator fields or numerical demonstrations; new video includes screen recording of a calorie calculator around ~18–22 s.
- Reuse reference video and JSON: `references/APPROVED_DUAL_FONT_STYLE_REFERENCE.mp4`, `D2_PRISM_APPROVED_DUAL_FONT_STYLE.json`. Reference appearance takes precedence over approximate numeric settings.
- No font files are bundled. Install legitimate Anton and Inter fonts only if absent; don't use an unapproved font substitute silently.

## Production rule
Before a full-length render, transcribe and translate accurately, produce one short preview, ask for approval. Do not build unrelated automation infrastructure or push to GitHub if permissions fail. Save reusable source/configurations and a downloadable final MP4 after approval.
